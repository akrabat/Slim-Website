We have released Slim 3.13.0 today, which supports PHP 8.1 through PHP 8.5.

This release is enables those who are still on Slim 3 to run on a more recent PHP, and so is recommended for all Slim 3 projects.

The GitHub release is [here](https://github.com/slimphp/Slim/releases/tag/3.13.0).
